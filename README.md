# Student Record Management System

This is a simple **Java CLI application** to manage student records. It demonstrates the use of:

- ✅ Object-Oriented Programming (Encapsulation)
- ✅ `ArrayList` for dynamic data storage
- ✅ Menu-driven CLI for CRUD operations

---

## 🔧 Features

- ➕ Add student
- 👀 View all students
- ✏️ Update student details
- ❌ Delete student record

---

## 🛠 Technologies Used

- Java
- VS Code (Recommended)
- Scanner class for user input
- `ArrayList` from Java Collections Framework

---

## 🚀 How to Run

1. Copy the code into a file named **`StudentManagementSystem.java`**
2. Open terminal in the project folder
3. Compile the code using:
   ```bash
   javac StudentManagementSystem.java


Run the compiled program:

java StudentManagementSystem
